# 🔹 UC03 — Atividade 01: Modelagem de Plataforma de Streaming

## 📌 Descrição
Modelagem conceitual e lógica de um banco de dados relacional para uma plataforma de streaming de vídeos sob demanda. O modelo abrange cadastros de usuários e seus endereços obrigatórios, associação de conteúdos com estúdios e histórico de visualizações através de uma entidade associativa ($N:N$).
