# 🔹 UC03 — Atividade 02: Gestão de Campeonato de Kart (DML e DCL)

## 📌 Descrição
Atividade focada na manipulação de dados (DML) e integridade referencial em um banco de dados para gestão de um campeonato de kart. Contempla a atualização de registros de etapas (`UPDATE`), remoção com tratamento de chaves estrangeiras (`FOREIGN KEY`), e gestão de patrocinadores, equipes e pilotos.
